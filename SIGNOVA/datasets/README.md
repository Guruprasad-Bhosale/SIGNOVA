# SIGNOVA External Datasets & Licensing

This directory details external dataset references, licensing constraints, and download instructions for SIGNOVA.

## Supported Reference Datasets

### 1. ISLTranslate
- **Citation**: Joshi et al., *ISLTranslate: Dataset for Translating Indian Sign Language*, ACL 2023.
- **License**: **CC BY-NC 4.0** (Non-Commercial Research).
- **Format**: 31,222 continuous ISL sentence and phrase translations in English.
- **Access**: [Hugging Face Exploration-Lab/iSign](https://huggingface.co/datasets/Exploration-Lab/iSign)

### 2. INCLUDE
- **Citation**: Sridhar et al., *INCLUDE: A Large Scale Dataset for Indian Sign Language Recognition*, ACM MM 2020.
- **License**: Non-commercial academic research.
- **Format**: 263 word-level signs, 4,287 videos across 7 signers.
- **Access**: [Zenodo Record 4010759](https://zenodo.org/records/4010759)
