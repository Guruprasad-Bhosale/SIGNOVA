# SIGNOVA Exploration Notebooks

Jupyter notebooks for development verification, dataset auditing, and visual landmark debugging:

- `00_environment_check.ipynb`: Verifies local GPU hardware, Python libraries, and VRAM status.
- `01_dataset_audit.ipynb`: Inspects ISLTranslate and INCLUDE dataset structures, distribution, and manifests.
- `02_visualize_landmarks.ipynb`: Visualizes 543 MediaPipe Holistic landmarks and spatial normalization overlays.
